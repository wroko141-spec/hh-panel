# HH панель

Панель вакансий hh.ru: подборки, фильтры, аналитика зарплат и навыков, избранное, сопроводительные письма, выгрузка в Excel.

**Демо:** https://wroko141-spec.github.io/hh-panel/

## Как устроено

- `collector.py` - сборщик. Открывает поиск hh.ru по каждой подборке из `searches.json`, достаёт вакансии из данных страницы и сохраняет в `data/vacancies.json` и `data/history.json`. Только стандартная библиотека Python.
- `index.html` - сама панель. Читает `data/*.json`, всё остальное считает в браузере.
- `update.sh` - сбор + выкладка на GitHub. На сервере запускается таймером раз в 6 часов.

Новые вакансии можно получать в Telegram: задайте `HH_TG_TOKEN` и `HH_TG_CHAT` в `~/.config/hh-panel.env`.

API hh.ru для соискателей закрыт (декабрь 2025), поэтому откликаться нужно на сайте hh: панель готовит письмо и открывает вакансию.
